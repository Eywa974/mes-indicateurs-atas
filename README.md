# Mes Indicateurs ATAS 📈

Bienvenue sur mon espace de téléchargement d'indicateurs personnalisés pour la plateforme ATAS.

⚠️ **Le code source n'est pas public.** Seuls les fichiers compilés (.dll) prêts à l'emploi sont fournis ici.

## 📥 Comment installer un indicateur ?
1. Allez dans la section **Releases** (à droite de cette page).
2. Cliquez sur la version la plus récente.
3. Téléchargez le fichier `.dll` de l'indicateur souhaité.
4. Fermez la plateforme ATAS.
5. Copiez et collez le fichier `.dll` dans le dossier suivant de votre ordinateur :
   `C:\Users\VOTRE_NOM\Documents\ATAS\Indicators\` ou
   `C:\Users\VOTRE_NOM\Documents\ATAS X\Indicators\`
   selon votre version d'ATAS
6. Redémarrez ATAS. L'indicateur apparaîtra dans votre liste !
