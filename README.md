# 🌐 Mes Indicateurs pour ATAS (Classic & ATAS X)

Bienvenue sur ma vitrine de téléchargement d'indicateurs personnalisés pour la plateforme de trading **ATAS**. 
Tous les outils proposés ici sont optimisés pour fonctionner à la fois sur **ATAS Classic** et **ATAS X**.

---

## 🚀 Liste des Indicateurs Disponibles

Cliquez sur l'indicateur de votre choix pour accéder à son mode d'emploi détaillé et ses spécificités :

*   [📌 Classic Pivot Points](./ClassicPivotPoints/) : Un système complet de points pivots avec gestion des sessions graphiques.
*   [📊 Account Info Display Replay](./AccountInfoDisplayReplay/) : Affichage des données du compte à l'écran, idéal pour les sessions de Replay.
*   [🔻 Triangle de Gann](./Trigann/) : Une impulsion, une correction, 3 points dessinent un triangle, un objectif. 
*   [📊 VolProf Daily](./) *(Bientôt disponible)* : Profil de volume quotidien optimisé.
*   [🎯 Cluster Statistic+](./) *(Bientôt disponible)* : Analyse avancée du carnet et des clusters.

## 💾 Comment les installer sur ATAS ?

Pour installer et utiliser un indicateur sur votre plateforme :

1. Allez dans l'onglet **Releases** à droite de cette page GitHub.
2. Téléchargez la dernière version du fichier correspondant à votre plateforme :
   * `Indicateur_Classic.dll` pour **ATAS Classic**.
   * `Indicateur_AtasX.dll` pour **ATAS X**.
3. Fermez votre plateforme ATAS.
4. Copiez le fichier `.dll` téléchargé et collez-le dans le dossier d'installation d'ATAS :
   * Généralement : `C:\Program Files (x86)\ATAS\Indicators\` (ou le dossier spécifique à ATAS X).
5. Relancez ATAS. L'indicateur apparaît désormais dans votre liste personnalisée.
